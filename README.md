# Word Quest

Play the game: https://tide-recording-continue-roller.trycloudflare.com

That page is the app. This file is only a short note. You can also open `index.html` in your browser.

A correct answer throws sparkles. Ten new words a day, harder as you go, a quiz every 30 words, and a 15-minute daily limit. When a round ends, the next day starts again at the beginning, so the words never run out. Progress stays in the browser.
